# Satoshi webfont

Source: Fontshare / Indian Type Foundry, official Satoshi download package:
https://api.fontshare.com/v2/fonts/download/satoshi

Font file: `Satoshi-Variable.woff2` (official, unmodified). Weight axis: 300–900. Use in CSS with `font-weight: 300 900`.

License: ITF Free Font License (FFL), version 2.0, 17 Aug 2026. The original license is included as `FFL.txt`. Section 01 permits self-hosting on the licensee's own website; Section 02 restricts redistribution of the font files through third-party font libraries or repositories. Obtain the official package directly from Fontshare for other projects.
